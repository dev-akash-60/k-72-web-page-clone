# k-72-web-page-clone

A modern, responsive creative agency website built with React, Tailwind CSS, and GSAP animations.

The project focuses on smooth page transitions, fullscreen navigation, interactive hover effects, and a bold visual design.

## 🚀 Tech Stack

- React
- JavaScript
- Tailwind CSS
- GSAP
- @gsap/react
- Vite

## ✨ Features

- Responsive design for desktop and mobile
- Fullscreen animated navigation
- GSAP-powered menu animations
- Staggered navigation transitions
- Animated hover effects
- Interactive navigation links
- Responsive typography
- Custom fonts
- Smooth visual transitions
- Mobile-friendly fullscreen menu
